# Vainilla Clothes 🌸

App simple y cute para la tienda Vainilla Clothes (Flutter, Android).

## Generar el APK con GitHub
1. Subí este proyecto a un repositorio de GitHub (rama `main`).
2. Entrá a la pestaña **Actions** → **Build APK** (corre solo al hacer push, o con **Run workflow**).
3. Cuando termine, bajá el artefacto **vainilla-clothes-apk** (contiene `app-release.apk`).

## Correr en local
```bash
flutter create --platforms=android .
flutter run
```
